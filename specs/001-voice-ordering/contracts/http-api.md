# Contract: HTTP API of `apps/web`

JSON over HTTPS. Request and response bodies are zod schemas in `packages/core/src/contracts/`,
shared by the web app, the staff app and the tests. Errors: `{ error: { code, message } }` with a
code from a closed set; Czech `message` for screens, English `code` for logs.

## Public (no login)

| Method & path                      | Purpose                                                                                                                | Body → Response                                                                                                                                                                                                     | FR                     |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `GET /api/catalogue`               | products and the days still open for ordering (open and before the cut-off)                                            | → `CatalogueResponse { bakeryName, cutoffDaysBefore, cutoffTime, products[], days[] }`                                                                                                                              | FR-014                 |
| `POST /api/orders/preview`         | price the order and read it back; saves nothing                                                                        | `WebOrderInput { customerName, customerPhone, pickupDate, items[] }` → `WebOrderPreview { …, lines[], totalCzk }`; errors 422 `closed_day`, `after_cutoff`, `unknown_product`, 409 `over_limit`, 400 `invalid`, 429 | FR-014, FR-040         |
| `POST /api/orders`                 | web form order, saved with source `web`                                                                                | `WebOrderInput` → `WebOrderPlaced { …preview, orderNumber }`; same errors; 10 orders per IP hash per hour (proposed, not measured)                                                                                  | FR-014, FR-040         |
| `POST /api/call/start`             | begin a browser call                                                                                                   | `{ caller_phone }` → `{ call_id, token, model, expires_at, cap_seconds }`; errors `rate_limited`, `quota_exhausted`, `voice_unavailable`                                                                            | FR-035, FR-036         |
| `POST /api/call/{id}/tools/{name}` | run a tool call from the Live session                                                                                  | tool arguments → tool result ([agent-tools.md](agent-tools.md))                                                                                                                                                     | FR-003–FR-008          |
| `POST /api/call/{id}/events`       | _not built (research R27)_: first-audio samples and usage arrive with `end`; a failed call ends with `reason: "error"` | —                                                                                                                                                                                                                   | FR-032                 |
| `POST /api/call/{id}/turn`         | cascade fallback: one customer turn as text                                                                            | `{ text }` → `{ say, tool_results[] }`                                                                                                                                                                              | ADR-0011               |
| `POST /api/call/{id}/end`          | end the call; prices the usage, records latency and the trace id                                                       | `{ reason, transcript[], first_audio_ms[], usage[] }` (`usage`: the Live `usageMetadata` reports as received) → `{ outcome, order_numbers[] }`                                                                      | FR-008, FR-009, FR-032 |

The call routes accept only a `call_id` issued by `/start` within its cap, from the same IP hash.

## Amendment 2026-11-25 — working a request (FR-047–FR-052, research R33)

| Method & path                                | Body → response                                                                                                                                                                                                                                                                                                     | Permission                        |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `GET /api/staff/requests`                    | each item gains `outcome` (`handled` · `unreachable` · null), `callingNow` (`{ name }` while a claim lasts, else null), `attempts` (unanswered count), `history` (`[{ kind, by, at, note, orderNumber }]`, oldest first), `orders` (for cancel/change with a phone: `[{ id, number, pickupDay, totalCzk, lines }]`) | `request:view`                    |
| `PATCH /api/staff/requests/{id}`             | `{ action: "call" \| "unanswered" \| "handled" \| "unreachable" \| "reopen", note? }` → `{ ok: true }`; `unreachable` without three attempts → 422 `too_early`; `call`/`unanswered` without a phone → 422 `no_phone`. Replaces `{ done }`.                                                                          | `request:resolve`                 |
| `POST /api/staff/requests/{id}/cancel-order` | `{ orderId }` → `{ ok: true, orderNumber }`; cancels the order and closes the request as handled in one transaction; 404 when the order is not among the request's orders                                                                                                                                           | `request:resolve`, `order:cancel` |
